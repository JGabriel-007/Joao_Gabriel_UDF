## ▶️ Como explorar os trabalhos

1. Baixe o repositório em **Code → Download ZIP** e extraia a pasta.
2. Abra a pasta no **Visual Studio Code**.
3. Escolha a disciplina e a atividade que deseja consultar.

- **HTML e CSS:** abra o arquivo HTML no navegador, mantendo as pastas de imagens e estilos nos locais originais. No TecBlog, comece pelo `index.html`.
- **C:** utilize um compilador de C para compilar e executar o arquivo escolhido. O VS Code, sozinho, não inclui um compilador.
- **Banco de dados:** abra os arquivos na ferramenta compatível com seu formato. Arquivos `.mwb` podem ser abertos no MySQL Workbench.

> Os trabalhos são atividades de aprendizado e podem receber correções e melhorias ao longo do curso.
